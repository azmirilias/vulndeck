What is deliberately excluded

  • Leaked or scraped data: no breach dumps, no stealer logs, no combolists.
  • Sources whose terms forbid redistribution (most commercial CTI APIs, Censys legacy search, Vulners).
  • Feeds that now require an API key before returning any data — abuse.ch moved its public downloads behind an auth key, so those feeds are only used where a free key is provisioned explicitly.
  • Anything requiring bypassing a bot wall. If a publisher closes access, the connector is disabled rather than worked around.
